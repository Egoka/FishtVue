## 💡 Найденные и исправленные проблемы

### 1. Экранирование спецсимволов ✅
**Проблема:** `.w-1/3` вместо `.w-1\/3`
**Решение:** Использование `replace(/[^a-zA-Z0-9-_]/g, "\\$&")` везде

### 2. Screen для height ✅
**Проблема:** `w-screen` = `100vw`, но `h-screen` = `100vh`
**Решение:** Явное указание разных значений для width/height

### 3. Size не поддерживает screen ✅
**Проблема:** `size-screen` не работает в реализации
**Решение:** Исключен из тестов size (см. unoRules.ts:121)
