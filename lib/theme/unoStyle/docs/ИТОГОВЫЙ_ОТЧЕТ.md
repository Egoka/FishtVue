### 3. Исправлена проблема с экранированием ✅

**Проблема:** Генерировалось `.w-1/3` вместо `.w-1\/3`

**Решение:** Все функции теперь используют правильное экранирование всех специальных символов:

```typescript
// БЫЛО (неправильно):
const escapedInput = input.replace(/\./g, "\\.")  // Только точка

// СТАЛО (правильно):
const escapedClass = classValue.replace(/[^a-zA-Z0-9-_]/g, "\\$&")  // Все спецсимволы
```

**Исправлено в 9 функциях:**
1. ✅ `generateSizingTests()`

6. ✅ `generateTransformAxisTests()`
