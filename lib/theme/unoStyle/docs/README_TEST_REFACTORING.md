## 🎓 Обучение

### Основные helper-функции

| Функция | Когда использовать | Экономия |
|---------|-------------------|----------|
| `generateFullColorTestSuite()` | Для любого цветового свойства | 70+ строк |
| `generateSizingTests()` | Для размерных значений | 20-30 строк |
| `generatePseudoClassTests()` | Для псевдо-классов | 10-30 строк |
| `generateBreakpointTests()` | Для responsive тестов | 10-15 строк |
| `generateGradientTests()` | Для from/via/to градиентов | 140+ строк |
| `generateSpacingTests()` | Для padding/margin/gap | 30-40 строк |

### Когда НЕ использовать генераторы

❌ Уникальные свойства:
```typescript
// НЕ генерируем - специфичная логика
{ classValue: "truncate", expected: ".truncate {\n  overflow: hidden;\n  text-overflow: ellipsis;\n  white-space: nowrap;\n}" }
```

❌ Сложные multi-property значения:
```typescript
// НЕ генерируем - слишком специфично
{ classValue: "sr-only", expected: ".sr-only {\n  position: absolute;\n  width: 1px;\n  height: 1px;\n  ...\n}" }
```

✅ Оставляйте такие тесты явными!
