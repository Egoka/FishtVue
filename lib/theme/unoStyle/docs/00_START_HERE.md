## ⚡ Быстрый старт за 2 минуты

### Шаг 1: Откройте Uno.test.ts

```typescript
// В начало файла добавьте импорт:
import { generateFullColorTestSuite } from "./test-helpers"
```

### Шаг 2: Найдите раздел "Text Color" (~строка 1590)

### Шаг 3: Замените весь раздел на:

```typescript
describe("Text Color", () => {
  it.each(generateFullColorTestSuite("text", "color"))(
    `tailwind($classValue)`,
    ({ classValue, expected }) => {
      expect(tailwind(classValue)).toBe(expected)
    }
  )
  
  // Специфичные тесты
  it.each([
    { classValue: "text-red-400/[.06]", expected: ".text-red-400\\/\\[\\.06\\] {\n  color: #f871710f;\n}" }
  ])(`tailwind($classValue)`, ({ classValue, expected }) => {
    expect(tailwind(classValue)).toBe(expected)
  })
})
```

### Шаг 4: Запустите тесты

```bash
npm test
```

### Шаг 5: Если работает - продолжайте! ✨
