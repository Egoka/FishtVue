# ✅ Исправление экранирования символов в test-helpers

## 🐛 Проблема

В helper-функциях использовалось неполное экранирование специальных символов:

```typescript
// БЫЛО (неправильно):
const escapedInput = input.replace(/\./g, "\\.")  // Экранирует только точку

// Для класса w-1/3 генерировалось:
expected: `.w-1/3 { ... }`  // ❌ Слеш не экранирован!

// Должно быть:
expected: `.w-1\/3 { ... }`  // ✅ Слеш экранирован
```

---

## ✅ Решение

Заменено на полное экранирование всех специальных символов:

```typescript
// СТАЛО (правильно):
const escapedClass = classValue.replace(/[^a-zA-Z0-9-_]/g, "\\$&")

// Теперь для w-1/3 правильно генерируется:
expected: `.w-1\/3 { ... }`  // ✅ Все спецсимволы экранированы
```

## 🎯 Что экранируется

Функция `replace(/[^a-zA-Z0-9-_]/g, "\\$&")` экранирует все символы кроме:
- Букв (a-z, A-Z)
- Цифр (0-9)
- Дефиса (-)
- Подчеркивания (_)

**Экранируются:**
- `/` → `\/` (слеш)
- `.` → `\.` (точка)
- `[` → `\[` (квадратная скобка)
- `]` → `\]` (квадратная скобка)
- `(` → `\(` (круглая скобка)
- `)` → `\)` (круглая скобка)
- `%` → `\%` (процент)
- `#` → `\#` (решетка)
- И все остальные спецсимволы
