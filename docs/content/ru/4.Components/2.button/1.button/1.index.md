## Overview

`Button` — обёртка над нативным `<button>` для запуска действий и отправки форм. Поддерживает три mode (`primary`, `outline`, `ghost`), четыре цветовых схемы (`theme`, `neutral`, `creative`, `destructive`), пять размеров, скругление углов и режим icon-only. Применяйте, когда нужен интерактивный триггер с типизированным API; для ссылок на маршруты используйте `<NuxtLink>`/`<RouterLink>`. Stability — **stable**, входит в библиотеку с версии **0.1.0**. Источник: [lib/button/Button.vue](lib/button/Button.vue).

## How it's organized

Файлы компонента в [lib/button/](lib/button):

| Файл | Роль |
|---|---|
| `Button.vue` | SFC, `<script setup lang="ts">`, шаблон рендерит `<button data-button>` |
| `Button.d.ts` | публичные типы: `ButtonProps`, `ButtonSlots`, `ButtonEmits`, `ButtonExpose`, `ButtonOption` |
| `Button.test.ts` | Vitest + `@vue/test-utils`, 14 кейсов |
| `package.json` | `main`/`module`/`types` для tree-shaking при `import Button from "fishtvue/button"` |

**Внутренние зависимости (только из lib/):**

- [Icons](lib/icons/Icons.vue) — рендер иконки (поддержка `@iconify/vue` и `@heroicons/vue`).
- [Loading](lib/loading/Loading.vue) — индикатор loading-состояния (тип `"simple"`).
- [FixWindow](lib/fixwindow/FixWindow.vue) — обёртка default-слота для `type="icon"` (поведение тултипа, `delay: 1000`, `padding-window: 40`).
- [Component](lib/component/index.ts) — базовый класс, поднимает lifecycle и инжекцию стилей.

**Внешних npm-зависимостей у Button нет** напрямую; транзитивно — те же, что у Icons / Loading / FixWindow (`@heroicons/vue`, `@iconify/vue`).

**Tree-shaking & bundle.** Точечный импорт `import Button from "fishtvue/button"` подтягивает только Button + его внутренние зависимости. Корневой `import { Button } from "fishtvue"` тянет весь публичный реестр компонентов — используйте только в исследовательских проектах. Бандл собирается через [lib/rollup.config.js](lib/rollup.config.js); итоговая точка — `lib/button/button.mjs`.

## How it works

**Lifecycle.** SFC создаёт `Button = new Component<"Button">()` ([lib/button/Button.vue:10](lib/button/Button.vue#L10)). Базовый класс автоматически регистрирует `onServerPrefetch` и `onMounted` для вызова `initStyle()` ([lib/component/index.ts:79](lib/component/index.ts#L79)). Дополнительно SFC явно вызывает `Button.initStyle()` в `onMounted` для надёжной инициализации стилей.

**Поток данных.** props → computed (`type`, `icon`, `iconPosition`, `isLoading`, `disabled`, `mode`, `size`, `rounded`, `color`) → итоговые `classBase` и `classIcon` (тоже computed) → шаблон. Watchers не используются. Каждый из `mode`/`size`/`rounded`/`color` читает значение по приоритету `props → options.{Button} → жёсткий default`.

**Стили.** `setStyle()` собирает базовые классы, классы режима, размера, скругления и опции (`options.class`, `props.class`) и инжектит их в CSS-layer `@layer fishtvue` через `useStyle()` ([lib/component/index.ts:179](lib/component/index.ts#L179)). На корневом `<button>` всегда присутствует селектор `fv fishtvue-button`, по которому работает override. Стили пересчитываются на изменение любого реактивного входа в computed.

**Конфиг.** Через `Button.getOptions()` читаются ключи `mode`, `size`, `rounded`, `color`, `class`, `classIcon` (тип [`ButtonOption`](lib/button/Button.d.ts#L151)). Передаются глобально через `app.use(FishtVue, { componentsOptions: { Button: { ... } } })`.

**Локализация.** Button **не вызывает** `t()` — внутри компонента нет локализованных строк, тексты приходят через слот.

**SSR / hydration.** Безопасен на сервере. Базовый класс `Component` использует `isClient()` для guard'а перед `useStyle()` ([lib/component/index.ts:179](lib/component/index.ts#L179)). Обращений к `document` / `window` / `navigator` в `Button.vue` нет. `<ClientOnly>` обёртка не требуется. Hydration mismatch'ев не зафиксировано: значения computed детерминированы по props и глобальному конфигу.

**Animation / transitions.** Стилевые transitions через Tailwind: `transition-colors duration-200`. Vue `<Transition>` и GSAP не используются. На `prefers-reduced-motion` компонент отдельно не реагирует — сами transition-colors короткие (200 ms) и вписываются в стандартные ожидания доступности.

## Quick Start

::preview
<DemoButtonSimple/>
::

```vue
<script setup lang="ts">
  import Button from "fishtvue/button"
</script>

<template>
  <Button>Нажми меня</Button>
</template>
```

Без обязательных props компонент рендерит mode `"primary"`, color `"neutral"`, size `"md"`, rounded `"md"`, type `"button"`.

## Examples

### 1. Базовый набор режимов

::preview
<DemoButtonBasic/>
::

```vue
<Button mode="primary" size="md" color="theme">Нажми меня</Button>
<Button mode="outline" size="sm" color="neutral" icon="check">Галочка</Button>
<Button mode="ghost" size="lg" color="destructive" :loading="true">Загрузка</Button>
```

### 2. С глобальной конфигурацией

```ts
// main.ts
import { createApp } from "vue"
import FishtVue from "fishtvue/config"
import App from "./App.vue"

createApp(App)
  .use(FishtVue, {
    componentsOptions: {
      Button: {
        mode: "outline",
        size: "lg",
        rounded: "full",
        color: "theme",
        class: "min-w-32"
      }
    }
  })
  .mount("#app")
```

После такой регистрации каждый `<Button>` без локальных props унаследует `outline`/`lg`/`full`/`theme` и базовый класс `min-w-32`. Локальные props всегда побеждают.

### 3. Icon-only кнопка с тултипом

::preview
<DemoButtonType/>
::

```vue
<Button type="icon" icon="check" rounded="full" color="creative">
  <template #default>Подтвердить</template>
</Button>
```

При `type="icon"` контент default-слота автоматически оборачивается в `<FixWindow>` (`delay: 1000 ms`) и работает как ленивый тултип. Сама кнопка получает квадратные размеры (`h-7..h-12 w-7..w-12 p-0`).

### 4. Интеграция со store (Pinia)

```vue
<script setup lang="ts">
  import { storeToRefs } from "pinia"
  import { useCartStore } from "~/stores/cart"
  import Button from "fishtvue/button"

  const cart = useCartStore()
  const { isSubmitting } = storeToRefs(cart)
</script>

<template>
  <Button
    mode="primary"
    color="theme"
    icon="arrow-right"
    icon-position="right"
    :disabled="isSubmitting"
    :loading="isSubmitting"
    @click="cart.checkout">
    Оформить заказ
  </Button>
</template>
```

`disabled` блокирует клики на уровне нативного `<button>`, `loading` параллельно показывает индикатор. Эмитов нет — реактивно подписываемся через стандартный `@click`.

## Compatibility & Stability

- **Минимальные версии:** Vue 3.5+, TypeScript 5.9+, Node 20+ (по корневому `package.json` engines не указан, но dev-зависимости требуют ≥20).
- **Nuxt:** Nuxt 3.x — supported. Nuxt 4 — экспериментально (используется в `sandbox-nuxt`, не в production docs).
- **Браузеры:** evergreen (Chrome / Firefox / Safari / Edge — последние 2 версии). IE не поддерживается.
- **Stability flag:** `stable` — компонент задокументирован, покрыт 14 тестами, TODO/FIXME в исходнике отсутствуют.
- **Breaking changes:** в `CHANGELOG.md` явных breaking-отметок для Button нет в окне 0.2.x. Последние правки — стилевые (см. 0.2.6: «Label visual updates», 0.2.10: «Table style fixes» — Button косвенно через общую тему).
- **Deprecations:** ни одного `@deprecated` в `Button.d.ts`.

### Incomplete or stubbed behavior

Нет. Все ветки шаблона и computed имеют рабочие пути.

### Skipped tests

Нет. В [Button.test.ts](lib/button/Button.test.ts) нет `it.skip` / `xit` / `xdescribe` / `it.todo`.

### API inconsistencies

Нет. Все props / slots / expose из `Button.d.ts` фактически используются в `Button.vue`. `ButtonEmits = null` — у компонента нет emit'ов, и шаблон их не объявляет.

### Behavioral caveats

- **`type="icon"` + default-слот.** Слот рендерится не внутри кнопки, а в `<FixWindow>` поверх неё с delay 1000 ms. Если ожидаете обычный inline-контент рядом с иконкой — используйте `type="button"` (или другой не-icon) и проп `icon` + `iconPosition`.
- **`loading: undefined` по умолчанию.** В `withDefaults` поле задано как `undefined` (не `false`). На атрибут `data-loading` это не влияет (приводится к строке), но если читаете `props.loading` снаружи через template ref — учитывайте, что значение тризначно (`true`/`false`/`undefined`).
- **Default `color` — `"neutral"`, не `"theme"`.** Большинство примеров в docs используют `color="theme"`, но без явного prop'а кнопка серая.
