## Configuration & Customization

### Global (через `app.use`)

Глобальные defaults задаются в `componentsOptions.Button` при регистрации плагина. Тип конфига — [`ButtonOption`](lib/button/Button.d.ts#L151) (`Pick<ButtonProps, "mode" | "size" | "rounded" | "color" | "class" | "classIcon">`).

```ts
// main.ts
import { createApp } from "vue"
import FishtVue from "fishtvue/config"
import App from "./App.vue"

createApp(App)
  .use(FishtVue, {
    componentsOptions: {
      Button: {
        mode: "primary",
        size: "md",
        rounded: "md",
        color: "theme",
        class: "tracking-tight",
        classIcon: "size-4"
      }
    }
  })
  .mount("#app")
```

Доступные ключи:

| Ключ | Тип | Описание |
|---|---|---|
| `mode` | `"primary" \| "outline" \| "ghost"` | Визуальный режим по умолчанию |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | Размер по умолчанию |
| `rounded` | `"none" \| "md" \| "lg" \| "full"` | Скругление углов |
| `color` | `"theme" \| "neutral" \| "creative" \| "destructive"` | Цветовая схема |
| `class` | `StyleClass` | Базовый CSS-класс, добавляется к каждой кнопке |
| `classIcon` | `StyleClass` | Базовый CSS-класс для иконки |

### Per-instance (через props)

Те же значения переопределяются прямо на инстансе:

```vue
<Button
  mode="outline"
  size="lg"
  rounded="full"
  color="creative"
  :class="['min-w-40']"
  classIcon="size-5"
  icon="check">
  Принять
</Button>
```

**Приоритет источников:** `props` > `componentsOptions.Button` > жёсткий default компонента (`mode: "primary"`, `size: "md"`, `rounded: "md"`, `color: "neutral"`, `iconPosition: "right"`, `type: "button"`, `disabled: false`, `loading: undefined`).

`class` и `classIcon` **складываются** (а не перезаписываются): `Button.setStyle(...)` собирает `[options.class, props.class]` в один итоговый массив через `cn()`.

### Theming

Button использует semantic-токены темы из [lib/theme/semantic.ts](lib/theme/semantic.ts) — палитры `theme-*`, `neutral-*`, `green-*`, `red-*` (последние две — для `creative` / `destructive` color схем).

| Color схема | Активные токены |
|---|---|
| `theme` | `theme-50..900` |
| `neutral` | `neutral-200..900` |
| `creative` | `green-100..900` |
| `destructive` | `red-100..900` |

**Dark mode** включён через классы `dark:*` Tailwind, переключается селектором `darkModeSelector` из глобальной темы (по умолчанию — `class` стратегия Tailwind).

**Override через кастомный theme:**

```ts
import { createApp } from "vue"
import FishtVue from "fishtvue/config"
import { Aurora } from "fishtvue/theme"

createApp(App)
  .use(FishtVue, {
    theme: {
      ...Aurora,
      semantic: {
        ...Aurora.semantic,
        theme: {
          ...Aurora.semantic.theme,
          500: "#7c3aed",
          600: "#6d28d9"
        }
      }
    }
  })
  .mount("#app")
```

После такого override все `Button` с `color="theme"` подхватят новые оттенки без дополнительных правок самого компонента.

**Префикс CSS-класса.** На корневой `<button>` всегда вешаются классы `fv fishtvue-button`. Используйте этот селектор для DevTools-инспекции и для override стилей (см. ниже).

### CSS layer override

Стили Button инжектятся в `@layer fishtvue` через `useStyle()`. Чтобы пользовательский override сработал, ставьте свои стили либо вне layer'ов, либо в более позднем `@layer`.

**Подход 1: пользовательский layer после fishtvue.**

```css
/* app.css */
@layer fishtvue, app;

@layer app {
  .fishtvue-button {
    letter-spacing: 0.02em;
    font-weight: 600;
  }

  .fishtvue-button[data-loading="true"] {
    opacity: 0.7;
  }
}
```

**Подход 2: стили вне layer'ов** (имеют более высокую специфичность, чем любой layer):

```css
/* app.css */
.fishtvue-button {
  letter-spacing: 0.02em;
}
```

**Подход 3: повышение специфичности внутри fishtvue layer:**

```css
@layer fishtvue {
  button.fishtvue-button.my-override {
    letter-spacing: 0.02em;
  }
}

/* в шаблоне */
<Button class="my-override">…</Button>
```

Полезные data-атрибуты для CSS-селекторов:

- `[data-button]` — корневой `<button>`.
- `[data-loading="true"]` — кнопка в loading-состоянии (курсор `cursor-wait`).
- `[disabled]` — стандартный нативный атрибут.

## Form integration & validation

Button — **не form-control** в строгом смысле (нет `modelValue`, нет `update:modelValue`/`change:modelValue`). Однако компонент полноценно интегрируется в форму через нативные form-events `<button>`-элемента и через FishtVue [Form](/components/form/form).

**Типы кнопок в форме:**

| Type | Поведение в `<form>` |
|---|---|
| `"button"` (default) | Никакого автоматического сабмита, обычный триггер |
| `"submit"` | Запускает submit формы; ловите через `@submit.prevent` на `<form>` или на `<Form>` |
| `"reset"` | Сбрасывает форму к initial state |
| `"icon"` | Внутри собирается с `type="button"` (не сабмитит) — иконочный триггер |

**Пример с компонентом Form:**

```vue
<script setup lang="ts">
  import Form from "fishtvue/form"
  import Input from "fishtvue/input"
  import Button from "fishtvue/button"

  function onSubmit(payload: Record<string, unknown>) {
    console.log("submit", payload)
  }
</script>

<template>
  <Form @submit="onSubmit">
    <Input name="email" type="email" required />
    <Input name="password" type="password" required />

    <div class="flex gap-2 mt-4">
      <Button type="submit" mode="primary" color="theme">Войти</Button>
      <Button type="reset" mode="ghost" color="neutral">Сбросить</Button>
    </div>
  </Form>
</template>
```

**Состояния:**

- `disabled` — выключает нативный `<button disabled>` (форма не сабмитится при клике, focus снимается).
- `loading` — визуально показывает индикатор и навешивает `cursor-wait`, но **не блокирует клик**. Если нужен block-on-loading — комбинируйте с `:disabled="loading"`.
- `error` / `success` / `warning` — отдельных состояний у Button нет; используйте `color="destructive"` / `creative` для семантической окраски действий.

**Поведение при reset формы.** Button не хранит внутреннее состояние и не реагирует на reset; reset обрабатывает [Form](/components/form/form), который вызывает сброс полей-наследников.

**Validation rules.** К Button не применимо. Валидация формы делается на уровне полей через [`rulesHandler`](lib/utils/rulesHandler.ts) и [Form](/components/form/form).
