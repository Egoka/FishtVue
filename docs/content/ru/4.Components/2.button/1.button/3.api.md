## Props

`ButtonProps` объявлен как **discriminated union** двух вариантов: [`SimpleButtonProps`](lib/button/Button.d.ts#L85) (с `type: "button" | "reset" | "submit"`) и [`IconButtonProps`](lib/button/Button.d.ts#L95) (с `type: "icon"`). Поле `type` дискриминирует ветку, всё остальное общее.

| Prop | Type | Default | Description |
|---|---|---|---|
| `mode` | `"primary" \| "outline" \| "ghost"` | `"primary"` | Визуальный режим. Default берётся из `componentsOptions.Button.mode` или жёсткого значения. |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | Размер кнопки. |
| `rounded` | `"none" \| "md" \| "lg" \| "full"` | `"md"` | Скругление углов. |
| `color` | `"theme" \| "neutral" \| "creative" \| "destructive"` | `"neutral"` | Цветовая схема. Большинство примеров в docs используют `theme`, но без явного prop'а кнопка нейтральная. |
| `class` | `StyleClass` | `undefined` | Дополнительный CSS-класс корневого `<button>`. Объединяется с `componentsOptions.Button.class`. |
| `classIcon` | `StyleClass` | `undefined` | Дополнительный CSS-класс иконки. |
| `icon` | `string` | `""` | Имя иконки. Принимается компонентом [Icons](lib/icons/Icons.vue) (`@iconify/vue` / `@heroicons/vue` нотации). |
| `iconPosition` | `"left" \| "right"` | `"right"` | Позиция иконки. При `type="icon"` игнорируется (иконка — единственный визуал). |
| `disabled` | `boolean` | `false` | Нативный disabled. Блокирует клики и убирает кнопку из tab-порядка. |
| `loading` | `boolean` | `undefined` | Показывает индикатор [Loading](lib/loading/Loading.vue). Не блокирует клик автоматически — комбинируйте с `disabled`. |
| `type` | `"button" \| "reset" \| "submit" \| "icon"` | `"button"` | HTML-тип кнопки. Значение `"icon"` переключает шаблон на icon-only ветку с тултипом для default-слота. |

`StyleClass` определён в [lib/types.d.ts](lib/types.d.ts#L105) как `string | Array<string>`.

## Events / Emits

`ButtonEmits = null` — у Button **нет emit'ов**. Подписывайтесь на нативные DOM-события через v-on:

```vue
<Button @click="onClick" @focus="onFocus" @blur="onBlur">…</Button>
```

### v-model contract

**Не применимо.** Button не принимает `modelValue` и не эмитит `update:modelValue` / `change:modelValue`.

## Slots

| Slot | Slot props | Description |
|---|---|---|
| `default` | — | Содержимое кнопки. Для `type="button" \| "reset" \| "submit"` — inline-контент рядом с иконкой. Для `type="icon"` — оборачивается в [`<FixWindow>`](lib/fixwindow/FixWindow.vue) и работает как тултип с `delay: 1000 ms`. |

`ButtonSlots` объявлен как `{ default(): VNode[] }` ([lib/button/Button.d.ts#L106](lib/button/Button.d.ts#L106)). Передаваемых slot props нет.

## Exposed methods

Доступны через template ref. Тип — [`ButtonExpose`](lib/button/Button.d.ts#L113).

| Name | Type | Description |
|---|---|---|
| `mode` | `ButtonProps["mode"]` | Текущий резолвнутый mode (после слияния props ↔ options ↔ default). |
| `size` | `ButtonProps["size"]` | Текущий size. |
| `rounded` | `ButtonProps["rounded"]` | Текущее скругление. |
| `color` | `ButtonProps["color"]` | Текущая цветовая схема. |
| `classBase` | `ButtonProps["class"]` | Итоговый CSS-класс корневого `<button>` (после `setStyle()`). |
| `classIcon` | `ButtonProps["classIcon"]` | Итоговый CSS-класс иконки. |

```vue
<script setup lang="ts">
  import { useTemplateRef } from "vue"
  import Button from "fishtvue/button"

  const buttonRef = useTemplateRef<InstanceType<typeof Button>>("buttonRef")

  function logState() {
    console.log(buttonRef.value?.mode, buttonRef.value?.size)
  }
</script>

<template>
  <Button ref="buttonRef" mode="primary" size="lg" @click="logState">Жми</Button>
</template>
```

## Accessibility & Security

### A11y

- **Нативная семантика.** Корневой элемент — `<button>`, отдельный `role` не выставляется. Браузер сам объявляет `role="button"`.
- **Клавиатура.** Поддержка нативная: Tab — фокус, Enter / Space — клик. Дополнительные `@keydown` обработчики не навешиваются.
- **Focus indicator.** Видимый ring через утилиты Tailwind: `focus:outline-none focus-visible:ring-1` + цветовые `focus-visible:bg-*` на active-состоянии.
- **Disabled.** Используется нативный `disabled` (а не `aria-disabled`). Кнопка убирается из tab-порядка, focus невозможен.
- **Loading.** Атрибут `data-loading="true"` и `cursor-wait`. **`aria-busy` Button не выставляет автоматически** — если индикатор loading должен объявляться screen-reader'у, добавьте `aria-busy="true"` через `:aria-busy="loading"` на самом `<Button>`.
- **Icon-only кнопки (`type="icon"`).** Без видимого текста screen reader озвучит только содержимое default-слота, обёрнутого в `<FixWindow>`. Тултип появляется по hover/focus с задержкой 1 s — для надёжной a11y дополнительно ставьте `aria-label`:

  ```vue
  <Button type="icon" icon="trash" aria-label="Удалить">
    <template #default>Удалить</template>
  </Button>
  ```

- **Reduced motion.** Анимации сводятся к `transition-colors duration-200`. Отдельной обработки `prefers-reduced-motion` нет — длительность вписывается в стандартные ожидания доступности.

### Security

- **HTML inject.** Button рендерит default-слот как обычный Vue-слот (без `v-html`), экранирование делает Vue. Если в слот передаётся внешний HTML — sanitize на уровне родителя (`sanitize-html` / `DOMPurify`).
- **CSP.** `Button.setStyle()` инжектит правила в `@layer fishtvue` через `useStyle()` ([lib/component/index.ts:179](lib/component/index.ts#L179)). Это создаёт `<style>` элемент с inline-CSS — для жёстких CSP-политик потребуется `style-src 'unsafe-inline'` либо nonce / hash для генерируемых правил. Inline-event-handlers и `eval` не используются.

## TypeScript

Все публичные типы экспортируются из `fishtvue/button`:

```ts
import type {
  ButtonProps,
  ButtonSlots,
  ButtonEmits,
  ButtonExpose
} from "fishtvue/button"
```

**Использование в parent-компоненте:**

```vue
<script setup lang="ts">
  import Button from "fishtvue/button"
  import type { ButtonProps } from "fishtvue/button"

  const config: ButtonProps = {
    mode: "outline",
    size: "lg",
    color: "creative",
    icon: "check",
    iconPosition: "left",
    type: "submit"
  }
</script>

<template>
  <Button v-bind="config">Подтвердить</Button>
</template>
```

**Template ref:**

```vue
<script setup lang="ts">
  import { useTemplateRef } from "vue"
  import Button from "fishtvue/button"

  const btn = useTemplateRef<InstanceType<typeof Button>>("btn")
</script>

<template>
  <Button ref="btn">…</Button>
</template>
```

`InstanceType<typeof Button>` корректно тянет `ButtonExpose`, потому что `Button` объявлен через `ClassComponent<ButtonProps, ButtonSlots, ButtonEmits, ButtonExpose>` ([lib/button/Button.d.ts#L11](lib/button/Button.d.ts#L11)).

## Testing recipes

Запуск тестов компонента:

```bash
pnpm test -- Button
# или watch
pnpm vitest -- Button
```

**Минимальный smoke-тест без плагина:**

```ts
import { mount } from "@vue/test-utils"
import { describe, it, expect } from "vitest"
import Button from "fishtvue/button/Button.vue"

describe("Button", () => {
  it("монтируется без падений", () => {
    const w = mount(Button, { slots: { default: "Hi" } })
    expect(w.find("[data-button]").exists()).toBe(true)
  })
})
```

**Mock FishtVue plugin** (нужен, когда тестируете parent, использующий Button с глобальной конфигурацией):

```ts
import { mount } from "@vue/test-utils"
import FishtVue from "fishtvue/config"
import Button from "fishtvue/button/Button.vue"

const wrapper = mount(Button, {
  global: {
    plugins: [
      [FishtVue, {
        componentsOptions: {
          Button: { mode: "outline", color: "theme" }
        }
      }]
    ]
  }
})
```

**Что обычно ломается:**

- *Cannot read properties of undefined (reading 'getOptions')* — забыли подключить FishtVue plugin при mount. Component class читает globalConfig через inject; без plugin вызов `Button.getOptions()` возвращает `undefined`, и часть computed валится. Лечится `app.use(FishtVue, {})` или передачей `global.plugins` в mount.
- *Loading иконка не появилась* — Loading рендерится только когда `loading=true` приведено к truthy. `loading: undefined` (default) не активирует индикатор.
- *type="icon" + slot — не вижу текст* — слот завернут в `<FixWindow>`-тултип, появляется по hover с delay 1000 ms. Это by design.

Эталонный набор кейсов в [Button.test.ts](lib/button/Button.test.ts) покрывает: defaults, props passthrough, рендер Icons + Loading, slot, expose, ветку `type="icon"` (включая FixWindow и rounded), а также интеграцию с глобальной конфигурацией.

## Troubleshooting / FAQ

| Проблема | Причина | Решение |
|---|---|---|
| Стили не применяются, кнопка выглядит как нативный `<button>` | Не подключён FishtVue plugin в `main.ts` — `Button.initStyle()` не успевает зарегистрировать CSS в `@layer fishtvue`. | Добавьте `app.use(FishtVue, { /* config */ })` хотя бы пустой конфигурацией. |
| TypeScript не находит `ButtonProps` | `tsconfig.json#compilerOptions.types` не включает `fishtvue` или `paths` указывают мимо. | Импорт через явный путь: `import type { ButtonProps } from "fishtvue/button"`. Убедитесь, что в `tsconfig` есть `"moduleResolution": "Bundler"` или совместимое. |
| `mode="primary" color="theme"` — цвета не совпали с дизайном | Активная тема (`Aurora` / `Harmony` / `Sapphire`) задаёт собственные `theme-*` токены. | Передайте свою тему в `app.use(FishtVue, { theme })` или override токены через `theme.semantic.theme`. См. [2.customizable.md#theming](#theming). |
| Тёмная тема не переключилась | `darkModeSelector` не применён к корневому элементу. | Проверьте, что Tailwind dark-mode стратегия и `optionsTheme.darkModeSelector` совпадают (обычно `class` стратегия + класс `dark` на `<html>`). |
| Override `.fishtvue-button { … }` в обычном CSS не работает | Стили компонента живут в `@layer fishtvue` — у обычного layer'а более высокая специфичность. | Поместите override в более поздний `@layer` (`@layer fishtvue, app;`) или вынесите вне layer'ов. См. [2.customizable.md#css-layer-override](#css-layer-override). |
| `loading` не блокирует клик | `loading` управляет только визуалом. | Свяжите с `disabled`: `:disabled="loading"`. |
| Icon-only кнопка не озвучивается screen reader | Без видимого текста и без `aria-label` ассистивные технологии не получают название. | Добавьте `aria-label` непосредственно на `<Button type="icon">`. |
